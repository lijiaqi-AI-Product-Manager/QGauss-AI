# 声音工作台语言与记录

文字配音、声音收藏室、聊天朗读和声音管理支持简体中文、繁體中文与 English。沿用站点的语言入口，日期、音色介绍、播放状态、费用确认和常见错误提示随当前选择更新。

切换语言保留草稿、音色、未提交搜索、当前记录和确认内容。已经开始的声音继续使用原任务与当前播放地址；暂停后的声音保持暂停，切换语言不会重新生成或扣次。用户自己的标题、正文和历史转写保持原文，模型与音色的技术标识保留。

收藏室可以使用显示音色名或原有音色标识搜索，包括简体、繁体、英文及全角字母。音色匹配与标题、原文匹配合并显示。录音转写仍可按标题和原文找到，不会因内部默认音色混入配音音色结果。已清理或超过保留期限的内容不会重新出现在搜索结果中。

次数回执分别列出预留、结算、退回与已过期的预留。退回部分和过期部分可以同时出现；信息不完整时提示继续核对，不显示为免费。切换语言不修改原回执。

声音管理继续要求管理权限，并使用统一外观与语言导航。正在填写但尚未保存的费用、渠道和保留设置会继续保留；切换语言不自动保存设置，也不发起试听或转写。

验证使用独立账号、有效样例音频和受控服务，覆盖原任务、内容与费用保持、账号隔离、查询和手机布局。真实声音质量及更多设备体验在服务配置就绪后继续验收。
