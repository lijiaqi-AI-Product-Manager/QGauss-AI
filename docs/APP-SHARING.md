# 应用分享与浏览统计

公开应用可从详情或作者工作台复制分享链接。访客打开链接后先展示应用档案，再由使用者选择是否开始新会话。浏览、收藏与复制链接不会生成回答或消耗次数。

分享浏览量记录从分享链接成功打开公开应用详情的次数，不代表独立人数。卡片、详情与作者工作台显示同一累计值；卡片在较大数值时缩写，完整数值保留在说明文字中。普通列表浏览、只读取链接资料或打开作者编辑页不累计分享浏览。

同次页面访问保留一个标识，网络重试、语言切换及账号状态刷新不会在该标识下重复累计。重新访问分享页面属于新的一次浏览。去重回执保留七天，累计值长期保留；旧应用从零开始，不补造历史浏览量。

统计结果暂未确认时，详情仍可浏览。详情中的“重新核对统计”继续同次访问。已有较新的统计结果不会被迟到的旧列表覆盖。计数不修改角色版本、最后编辑时间、审核事件或奖励。

私用、待审核、撤回、回收或作者停用的应用不接受公开浏览统计。撤回后即使重试旧回执也不会重新开放分享；作者仍能在本人记录中查看已有累计值。公开接口只返回应用标识、累计数和本次是否累计，不提供访问者明细。

页面显示支持简体中文、繁體中文与 English。语言变化保留应用名称、介绍、角色原文、审核反馈、图片裁切位置及未完成的保存操作。
