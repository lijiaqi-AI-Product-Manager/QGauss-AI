# QGauss 扩展工作台

成员从 `/extend` 打开工具卡片。内置灵感便签可以保留当前窗口的草稿，将想法整理成计划、点子或文字，并与站点同步深浅色。管理员在 `/extensions/manage` 添加独立 HTTPS 页面，设置图标、卡片颜色、排序、可见范围、对话权限与指定模型；扩展可以停用、移入回收站和恢复。

扩展提出问题后，工作台先展示完整问题、模型和本次次数。使用者确认后才接受生成。回答同时回到发起请求的画布，并保存到本人的普通对话记录；费用与停止生成沿用对话记录的结算规则。浏览扩展、编辑便签和读取费用均不调用模型。站点尚未接通模型时，便签仍可使用，发送会提示尚未准备好。

每次确认使用一个稳定请求标识。准备、生成、核对与恢复均围绕原请求进行；核对不会重新提问。网络中断后可核对或明确继续原请求，也可结束尚未接受的等待。结束结果会阻止迟到的准备重新启动。已接受的请求停止后，先确认保存结果及退回次数。失败或取消的原请求再次重放仍返回原记录，重新创作需要新的明确确认。

回执固定指向最初接受的回复，不包含后来在普通对话里创建的分支。会话或消息删除后，不再向扩展返回原内容。账号变化会清除当前画布；重新打开的画布不会自动收到上一个画布的回复。草稿按账号、入口和配置版本隔离，只保留在当前窗口的临时存储中。

## 页面接入

外部页面使用独立 HTTPS 域名，不在地址中携带访问凭据。管理员需确认页面允许 QGauss 站点嵌入。站点对画布限制导航、弹窗、设备和剪贴板权限，使用 `referrerpolicy="no-referrer"`。消息同时匹配 iframe 窗口、精确来源与当前连接标识。站点登录凭据不会交给扩展。

可以将 `/extensions/qgauss-bridge.js` 放入扩展自己的静态资源，再以普通脚本加载。脚本提供以下接口：

| 接口 | 用途 |
|---|---|
| `QGaussBridge.onReady(callback)` | 读取当前画布是否开放对话 |
| `QGaussBridge.onTheme(callback)` | 接收 `light` 或 `dark` |
| `QGaussBridge.setTheme(mode)` | 请求同步站点主题 |
| `QGaussBridge.requestChat(prompt, { onProgress })` | 等待使用者确认并返回最终文字，失败时拒绝 Promise |
| `QGaussBridge.onDraft(callback)` / `saveDraft(text)` | 内置画布专用的窗口草稿 |

每个画布同时只保留一个待处理请求。`onProgress` 可接收 `review`、`running`、`recovering` 与 `canceling`。结果尚未确认时，应提示使用者在工作台核对。画布意外跳转后，需要在工作台重新打开才能建立新连接。

消息协议为 `channel: "qgauss-extension"`、`version: 1`。扩展先发送 `ready`；宿主返回 `init`，携带 `nonce`、`mode`、`title` 和 `capabilities.chat`。后续消息携带该 `nonce`。对话使用 `chat`、`id`、`prompt`，宿主以 `ack`、`result` 或 `error` 响应；结果文字字段为 `text`，错误字段为 `message`。相同 `id` 与内容的重放复用原结果。

管理员可为既有独立域名扩展明确开启基础格式兼容。基础格式支持 `{ type: "theme", data: "dark" }` 和 `{ type: "chat", data: "问题" }`；同样需要精确窗口与来源匹配，以及使用者在工作台确认。新页面应使用带连接标识的完整协议。

## 配置与维护

扩展写入携带当前版本和稳定操作标识，防止覆盖别处已更新的设定。保存回执丢失时，管理页保留原操作，可核对或重试相同操作。入口、模型或价格变化后，尚未接受的请求需要重新确认；已经接受的回复按接受时保存的费用结算。

新增 `extensions`、`extension_requests` 两张表，使用迁移 `0036_extension_workbench.sql`。升级不会写入样例工具或变更既有菜单配置；客户端和管理页提供扩展入口，内置便签首次使用前以只读默认项展示。

自动检查包含消息来源与连接隔离、真实 Vue 确认流程、配置版本冲突、回执恢复、账号切换，以及隔离数据库下的实际对话、流式回复、停止与次数结算。模型质量、外部扩展服务可用性和正式站点设备覆盖仍需结合实际部署验收。
