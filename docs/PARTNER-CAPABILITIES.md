# 行动搭档能力档案

搭档档案展示已保存的模型、工具、工作流及知识资料。名称和说明保留服务方原文，界面标题、费用说明及操作提示支持简体、繁体和英文。

资料明确包含空清单时，显示尚未配置。没有提供清单、旧记录只保留数量，或内容不完整时，显示待补齐；不把缺失资料当作没有能力。较长清单展示前 20 项，同时保留已确认的总量。模型、工具与知识的内部标识、授权、变量和提示词不进入公开档案。

资料取自已保存的已发布版本。[服务配置字段](https://docs.coze.cn/developer_guides_get_metadata_draft_published)包括模型、插件、工作流和知识清单。管理员同步资料后更新档案同步时间；用户点击“刷新资料”只核对本站最新档案，不向服务方发起生成。

## 准备一次协作

开始前核对搭档状态、当前费用和资料回执。未完成连接、费用缺失或资料尚未确认时，暂停开始入口。建议问题只打开会话并填写草稿，由本人决定发送。

刷新时保留正在阅读的档案，暂停开始入口；读取失败会明确说明，搭档下架后移除旧档案。切换语言和外观不刷新列表、重新收藏或发送问题，名称、搜索条件和草稿保持原样。

## 资料变化与原会话

发送前发现搭档资料或费用变化时，暂停旧入口并要求重新核对。原输入未被继续编辑时，问题原文和附件带回编辑区；等待期间有新编辑时，保留新内容，原问题仍可从本轮记录编辑带回。未受理的旧问题不会作为新一轮的已完成上下文再次发送。

已经收到任务回执的错误保留原轮次，不按未受理请求处理。切换页面后从历史继续读取原会话；停止生成和服务方取消回执继续分别展示，预留、结算、释放及到期沿用原记录。
