# 声音渐进播放

回答朗读、音色试听和文字配音可以在整次生成结束前开始播放。声音工作室提供“边生成边播放”选择，也可以先安静生成，再亲自点击播放。编辑区继续保留新的草稿，本次声音始终使用确认时的文字和音色。

支持连续音频的浏览器会在收到有效音频后开始播放。其他浏览器在首段保存后开始，后续片段准备好再衔接。长正文采用较短的第一段，并尽量沿句子划分；文字和表情完整保留。生成中的总时长尚未确定时显示“接收中”。

暂停播放不会停止生成。暂停后的新片段继续留给原任务，重新同步进度不会擅自恢复声音；继续播放沿用当前声音。需要停止生成时，使用独立的“请求停止生成”按钮。停止结果等待确认期间，播放和停止按钮避免重复操作。

播放连接中断后，“重新连接播放”读取同一个已接受任务，可能从开头重听。重连、暂停、重听和保存不会重新向声音服务提交生成，也不会产生另一笔生成费用。浏览器限制自动播放时，页面保留声音并提供亲自点击的入口。

次数先按确认结果预留。整次声音完整成功后结算，失败或明确停止继续按原回执规则退回可用次数。未完成的声音只是临时播放内容，失败或停止后停止开放；完整成功的结果才进入可保存的声音作品。完整保存仍合并原结果，不重新生成。

声音只供本人读取。退出账号、切换会话、撤回登录、登录到期或移除源内容后，旧播放停止或要求重新连接。长连接持续检查原登录和来源，不将连接鉴权信息加入个人资料或回执。公开管理回执不提供私人声音播放地址。

验证使用隔离账号、有效的本地 MP3 和可控延迟服务。真实声音质量、不同设备的自动播放体验与实际服务账单仍需在接入配置后验收。
