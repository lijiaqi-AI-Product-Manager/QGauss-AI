# 界面语言与设备偏好

首次进入时，界面根据浏览器的语言顺序选择简体中文、繁體中文或 English。已有手动选择优先，语言选择器也可重新切回“跟随设备”。中文的书写体系优先于地区；没有明确书写体系时，台湾、香港和澳门使用繁体。设备没有支持的语言时使用简体中文。

登录、通用导航和管理界面使用同一份选择。手动选择会在当前浏览器保留；跟随设备时会响应设备语言变化。其他页面修改语言后，已打开的页面读取最新偏好。页面启动时同步文档语言，避免已选择英文但页面标记仍是中文。

浏览器不允许读取或保存偏好时，页面仍能启动，选择会立即生效，并提示“仅本次”。尚未保存的手动选择保留在当前页面，不被旧的跨页面事件覆盖。无法保存公告关闭状态时，本页仍可关闭公告；外观设置同样说明临时生效状态。

请求提示按当前界面语言读取。同一次页面中的对话订阅在断线恢复时保留开始时的请求语言，重新打开历史记录使用当前界面语言，始终读取原任务；切换语言不重复提交问题、生成或费用操作，也不改写正在编辑的文字与账号状态。现有后端提供英文通用错误提示和中文业务详情，错误编号与业务结果不变。

现已覆盖登录入口、通用导航、三套首页构图、灵感卡片、会话侧栏、常用对话操作、外观设置，以及应用发现、创建、审核、图片裁切与应用管理。表格空状态、分页和确认框的通用提示也跟随语言。其他独立创作页面和业务详情的完整语言覆盖仍在补齐。应用名称、角色原文、审核反馈、模型与分类名称、用户内容、自定义菜单及站点公告保留原始内容。

访客应用页与应用详情内均可选择语言。切换语言更新显示文字，不重新加载应用、关闭编辑窗口或提交保存与审核；裁切画布与缩放位置保留。统计回执尚未确认时，切换语言或重试沿用同次访问标识。

聊天创作区、模型选择与发现、协作状态、联网来源、对话目录和阅读工具支持三种语言。切换时保留草稿、附件、筛选、详情、比较以及已接受的生成任务；代码复制状态、图表原文视图、缩放方式和阅读位置也保留。用户文字、模型名称与标识、实际厂商名称、引用内容、协作提问与产物保持原文。能力筛选支持三种语言和全角输入。

次数回执区分预留、结算、释放和会员额度到期，明确为零时可以展示未扣次数；不完整或无效的数据显示待核对。用量区分模型报送和估算，不将缺失信息显示为零。界面语言不改变次数、模型入口或费用计算。应用设定过期时依据接口状态停止使用旧设定；资料暂不可读时只核对访问状态，保留当前问题和模型，不自动提交。

验证包括设备语言顺序、中文书写体系、旧偏好、受限存储启动、跨页面更新、手动选择、文档标记、四类请求传输及对话恢复，并检查实际登录页面、三套外观、键盘与手机布局。
