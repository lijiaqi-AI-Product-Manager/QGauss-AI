# 手机账户与验证

账户入口支持邮箱／登录名与手机号码切换，各自保留当前页面中尚未提交的内容。手机使用中国大陆 `+86` 号码：已有账户通过号码和密码登录，新账户通过短信验证后设置登录名与密码。手机账户可以不填写邮箱，个人空间不会显示虚构的邮箱地址。

找回密码需要确认号码和六位验证码，再填写两次新密码。成功后，该账户的已有登录与未使用的邮件重置链接失效，作品和余额保留。已登录账户可以在“个人空间 → 登录与密码”确认当前密码、验证新号码并绑定；绑定不修改密码，不合并其他账户。

## 开启短信

在服务端环境中填写下列配置，重启后由管理员访问 `GET /api/auth/phone/configuration` 核对准备状态。配置检查不发送短信，服务凭据不会返回页面。

| 配置 | 用途 |
|---|---|
| `SMS_ENABLED=true` | 开启短信发送 |
| `SMS_ACCESS_KEY_ID`、`SMS_ACCESS_KEY_SECRET` | 服务端调用凭据 |
| `SMS_SIGN_NAME` | 已审核通过的 QGauss 短信签名 |
| `SMS_TEMPLATE_CODE` | 已审核通过的验证码模板编号 |
| `SMS_CODE_VARIABLE` | 模板中的验证码变量名，默认 `code` |
| `SMS_SECURITY_TOKEN` | 使用临时凭据时填写 |

当前对接中国大陆短信接口，使用固定服务地址和 HTTPS 签名请求。签名、模板及真实收信仍需由部署者分别验收。参见[发送接口](https://help.aliyun.com/zh/sms/developer-reference/api-dysmsapi-2017-05-25-sendsms)和[请求签名说明](https://www.alibabacloud.com/help/en/sdk/product-overview/v3-request-structure-and-signature)。未准备短信时，页面明确提示不可申请；已绑定号码仍可使用密码登录。

## 等待与恢复

验证码有效期为五分钟，申请间隔至少一分钟。注册、找回密码、绑定和首次安全设置分别核对，每个验证码只用于一次操作。错误尝试最多五次；同一号码最近二十四小时最多接收十次申请，同一来源最多三十次，全站上限由 `security.smsDailyLimit` 设置，默认为一千次。

点击申请后先保存申请记录。发送方接受请求代表提交成功，实际收到短信仍需本人确认；发送结果不明时可以核对原申请，不会自动重新发送。明确结束等待会让未完成的验证码失效，已经完成的注册、改密或绑定不会撤销。浏览器仅保存当前账户、用途对应的申请编号，不持久保存号码、密码或验证码。

升级包含账户邮箱字段的兼容调整。部署前应完成加密备份、完整性检查和升级演练，保留已有账户标识、创作记录、权益及配置。回退程序需要配套支持空邮箱的数据访问组件，不能直接沿用要求邮箱必填的旧组件。

外部身份首次进入的账户可验证本人手机号并设置第一把密码，无须提供尚未设置的旧密码。成功后已有登录失效，返回手机登录入口；再次登录后核对旧设置结果不会退出当前新登录。详见[扫码登录与身份关联](EXTERNAL-IDENTITY.md)。
