# 管理端对话记录

管理员可以在「对话记录」按内容、用户名或邮箱、用户编号、会话编号、完整模型名称、消息角色、处理状态、费用状态、对话类型和日期查找消息。`%`、`_` 按字面文本查找。使用中与回收站有明确范围；已单独移除的消息不返回。

查询与表单编辑分开。编辑后点击「查询」才应用；翻页和导出沿用已应用的条件。翻页使用同一查询时间，之后新建的消息不会挤入当前查询。相同时间按记录编号排序。原消息的状态仍可能继续更新，读取或导出并不锁定后续业务处理。

明细展示完整消息、已保存的推理内容、上条消息和同一问题的回复分支。费用凭据分别说明当前预留、实扣、返还和已到期数量；处理中不代表已扣次。旧消息未记录用量或费用时保持空缺，不能当作零。分支列表最多显示前 100 条，并明确总数。

导出 Excel 保留记录编号、用户、会话、角色、状态、模型、用量、费用及消息文本。开始前检查单次不超过 20000 条、当时文本总量不超过 64 MiB；超过上限会要求缩小范围。长文本按段保留，每段有序号，完整内容和推理均可按记录编号重组。分段行重复显示费用，汇总时需按记录编号去重。超过单张工作表行数时继续写入下一张；「导出说明」保留筛选条件、选中数和实际导出数。

导出固定开始时选中的消息范围，逐批核对最新状态。期间已移除或不再符合筛选条件的消息不导出。换账号、权限变化、重新查询和主动取消会结束当前读取或下载；较早的响应不能覆盖新页面，也不能开始迟到的文件下载。

记录、明细与导出仅向管理员开放。接口仅选择公开记录字段，不返回渠道密钥、渠道编号、内部结算快照、原始工具参数和供应商内部任务标识。导出途中定期核对管理员状态，客户端断开后停止整理文件。
