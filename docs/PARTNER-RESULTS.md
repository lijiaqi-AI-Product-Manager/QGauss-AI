# 搭档协作过程与成果

协作面板分开展示工具记录、工作流记录和独立成果。数字表示本轮收到并可展示的记录数量，不代表服务方的调用总次数或实际用量。过程可以展开或收起；查看记录和切换语言不重新生成，也不改动正在编辑的问题。

每项记录分别显示已返回、等待返回或返回未确认。整轮完成、失败和中断继续单独说明。没有过程记录时，明确说明本轮未提供记录；未收到某一步的返回，不直接认定执行失败。最多展示 24 条过程记录，新回执超过上限时说明部分后续记录未收录。

## 对应与重复回执

能够确认属于同一条消息或同一次调用的重复回执，不重复计入记录。同一组工具中的不同操作分别对应返回；明确的调用标识可以对应乱序回执。没有足够资料区分多项等待中的操作时，返回保留为独立记录，原步骤继续待确认。

对接遵循[对话事件说明](https://docs.coze.cn/developer_guides_chat_v3)。工具返回兼容 `tool_response` 和 `tool_output`；参数、原始结果正文、服务方内部标识不会进入公开过程面板。工具与工作流名称保留原文；本站补充的通用标签支持简体、繁体和英文，不改写服务方同名内容。

## 成果与下一步

图片和文件显示为独立卡片，保留名称、目标域名和明确的打开入口。页面不会预先加载远程图片或文件；点击后打开服务方链接，并说明链接可能有有效期。未提供可展示的独立成果链接时，继续查看本轮回复。

后续问题只填入草稿，由本人决定是否发送。从历史恢复仍读取原轮次；重新生成创建独立版本。已完成版本的成果和结算记录继续保留，停止新版本不会把旧成果算到新版本，也不会把新版本未确认的步骤改为完成。
