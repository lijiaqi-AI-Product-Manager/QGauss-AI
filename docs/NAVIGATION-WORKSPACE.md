# 导航工作台

管理员从账户菜单打开“导航工作台”。创作入口和管理入口各自整理，可按用途搜索，添加分组或入口，调整同组顺序和显示状态，并分别设置简体、繁体、英文名称及提示。自定义名称和技术标识原样保留。

入口支持站内页面、外部 HTTPS 链接与嵌入画布。站内页面从已有功能中选择；画布只在打开该入口后载入。图标可选择普通及选中状态的图形，也可上传图片或填写图片地址。上传图片在浏览器整理为 128 × 128 PNG。外部图片读取失败时保留图形替代。

展示区域、设备和可见角色分别设置。父分组收起或不在可见范围时，组内入口不会单独出现。需要登录的入口先进入登录页，管理页面仍须通过实际账户权限检查。公开导航不返回受登录保护的外部目标地址。导航可见设置不替代功能自身的权限和费用确认。

## 保存与恢复

编辑、预览、搜索和切换语言均不保存。先“预览这次调整”，核对变化后确认；只保存已改的字段，一次调整共同生效。多人编辑或值发生往返变化时，保留本人草稿并要求明确选择最新内容或保留本人修改，之后重新预览。

回复中断后，使用“核对原结果”读取原申请；不会自动重新提交。处理编号仅保存在当前浏览器会话中，保存内容和认证凭据不随编号存储。管理员只能核对自己仍有权限读取的申请。结束尚未受理的等待会保留草稿，已保存结果仍以原结果为准。

“收起到回收站”会先列出相关分组和入口，确认后收起。恢复时保留名称、图标、顺序与目标，并核对需要恢复的父分组。已单独收起的旧入口不会因恢复另一批次而自动加入。没有永久删除入口。

## 兼容与验收

已有菜单原字段和值保留；新增字段通过第 50 次迁移补齐。首次读取只在内存补充缺少的标准入口，明确保存后才初始化。初始化后按已保存结果展示，包括全部隐藏或回收的空导航，不自动重新插入默认入口。

工作台使用三套现有主题，提供三种界面语言、窄屏布局及减弱动态支持。保存通知只包含短期去重标记；其他页面重新读取实际导航，切换账号立即丢弃旧账号的界面数据和迟到回复。当前验证使用隔离数据库与合成账户，不能替代真实外部服务、完整设备范围及全部页面的验收。
