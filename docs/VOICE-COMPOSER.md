# 声音工作室

`/voice/create` 提供独立文字配音。成员可以为作品命名、编辑文字、选择六种音色，并试听固定介绍文字。配音和试听都先展示本站次数，明确确认后才提交生成。长文字按句子分段，整次任务按确认的次数结算一次；进度显示已保存的片段数量。

完成后可以逐段回放、调节播放速度、保存完整 MP3，或进入声音收藏室。播放速度只影响本次回放，不重新生成。保存读取已经生成的音频，不调用模型。多段 MP3 整理时去除重复标签与过期索引；如果片段格式不兼容，会返回明确错误，保留分段结果，不输出不完整文件。

声音收藏室保留作品名称和独立配音的完整原文。成员可以把原文带回工作室再编辑；已有草稿需要明确选择后才替换。带回文字不会启动生成。原文、声音和私有记录遵循接受时固定的保存期限，到期立即停止开放，清理时撤回原文和音频，已结算回执保留。

工作室的草稿和待核对请求只保留在本人当前窗口，登出时清除。提交前同步保存稳定请求标识；网络中断和页面返回先读取原任务，重试沿用原内容和标识，不创建重复任务。明确结束未接受的等待会留下持久记录，阻止迟到提交重新启动。已接受的任务通过停止入口处理，完成与停止竞态以保存结果和费用回执为准。

## 接口

| 接口 | 行为 |
|---|---|
| `GET /api/voice/options` | 音色、文字上限、可用状态和次数 |
| `POST /api/voice/quote` | 核对 `kind: "speech"`、`text`、`title`、`voice`；返回内容与费用版本 |
| `POST /api/voice/tasks` | 相同正文与费用版本，加 `requestKey`、`quoteRevision`，接受一次任务 |
| `GET /api/voice/tasks/by-request/:key` | 按本人稳定请求读取原任务 |
| `POST /api/voice/requests/:key/end` | 明确结束尚未接受的请求 |
| `GET /api/voice/tasks/:id/audio/:index` | 本人鉴权读取已经保存的片段 |
| `GET /api/voice/tasks/:id/download` | 本人鉴权保存完整 MP3 |

独立配音不能同时指定对话回答、录音或试听来源。正文上限由声音控制台设置，名称最多 80 字符。正文保持段落和表情；首尾空白在确认时归一。原有回答朗读、音色试听和录音转写入口继续使用各自来源，不接受额外正文覆盖原内容。

新增迁移 `0037_voice_requests.sql`，保存原请求、作品正文和结束状态。原请求与声音任务在同一接受事务中保存；结束后的请求编号、失败和取消后的原任务不会自动生成第二次。管理费用回执不包含原文、作品名称或音频入口。

自动检查覆盖真实 Vue 编辑与确认、账号隔离、草稿冲突、请求恢复、停止、次数预留和结算、保存期限、完整音频导出及清理。音频格式另经本机解码验证。界面演示和自动检查使用本地合成数据；真实供应商的声音质量和账单需要配置后单独验收。
