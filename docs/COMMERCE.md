# 运营与计费

商业入口由 `commerce.enabled` 控制，默认关闭。开启后提供次数权益、会员套餐、卡密、订单、支付、签到与分销。

金额使用整数分，模型成本使用整数微；两者通过统一金额函数换算。基础、高级、绘画和应用各有独立次数池。扣减先使用有效会员每日额度，再使用购买次数。

生成接受时保存价格与权益快照，并原子建立次数预留。成功后结算，失败或取消返还；已保存结果在重启后只继续结算，不重新调用服务。所有变更通过统一账本入口写入，并保留引用与流水。

订单保存接受时的商品快照、金额与有效期。商品后续变动不改变新订单已接受的权益。缺少历史快照的旧订单保留兼容规则，不推测填充。回调验签后以条件更新与唯一约束防止重复到账和重复分佣。

卡密保留生成时的权益快照。每人一次的核销规则以用户与卡密的唯一约束实现。签到、提现申请及重复支付通知均使用明确的重复处理规则。

提现区分申请、审核和登记打款。登记完成只代表站内处理记录，不推断银行到账。开放真实收费前，应分别验证支付、退款、费用、履约、分销与对账。
