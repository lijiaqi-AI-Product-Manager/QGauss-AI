# 运营与计费

商业入口由 `commerce.enabled` 控制，默认关闭。开启后提供次数权益、会员套餐、卡密、订单、支付、签到与分销。

金额使用整数分，模型成本使用整数微；两者通过统一金额函数换算。基础、高级、绘画和应用各有独立次数池。扣减先使用有效会员每日额度，再使用购买次数。

生成接受时保存价格与权益快照，并原子建立次数预留。成功后结算，失败或取消返还；已保存结果在重启后只继续结算，不重新调用服务。所有变更通过统一账本入口写入，并保留引用与流水。

订单保存接受时的商品快照、金额与有效期。商品后续变动不改变新订单已接受的权益。缺少历史快照的旧订单保留兼容规则，不推测填充。回调验签后以条件更新与唯一约束防止重复到账和重复分佣。

卡密保留生成时的权益快照。每人一次的核销规则以用户与卡密的唯一约束实现。签到、提现申请及重复支付通知均使用明确的重复处理规则。

管理员可以在订单管理按订单号、交易号、状态、支付通道和北京时间的下单日期筛选。汇总卡覆盖完整的筛选范围，模拟付款金额单列。支持导出本页订单和逐单核对单。

逐单核对会比对已验证的支付通知、下单时的权益、到账记录和佣金凭证，标记待人工核对的差异。旧单缺少凭证、已退款订单和缺少下单快照的情况保留原记录。核对单使用站内数据，渠道账单、退款凭证、费率与实收仍需在商户侧核对。

商户账单位于管理员的运营区，商业入口关闭时也可使用。选择所属收款通道并上传 CSV，每份文件最多 3000 笔、1 MB，支持 UTF-8 和 GB18030。预览显示金额、记录样例、排除记录和出错行，确认后才保存核对结果。

- QGauss 标准模板填写收款或退款、渠道流水号、订单号或交易号、北京时间和整数分金额。收款与退款金额均填正数。手续费可留空，扣收填正数，退回填负数。完整账期可检查该通道的站内已支付订单是否缺少收款行，日期范围最多 31 天。
- 微信支付原始交易 CSV 使用订单金额和申请退款金额核对，按商户订单号匹配站内订单。预览列出被排除的撤销和未成功退款。支持明细中的全量、收款及退款账单格式。按文件逐笔核对。[账单字段说明](https://pay.wechatpay.cn/doc/v3/merchant/4013071246)
- 其他渠道 CSV 可按列选择流水号、商户订单号或网关交易号、时间和人民币金额单位。可指定单一记录类型，也可从文件列读取类型。按文件逐笔核对。

渠道退款标为待复核，可登记结论、重新打开并按状态导出。账单金额及导入时的站内数据保留在核对记录中。正式收款、退款及实际结算需另行联验。

提现区分申请、审核和登记打款。登记完成只代表站内处理记录，不推断银行到账。开放真实收费前，应分别验证支付、退款、费用、履约、分销与对账。
