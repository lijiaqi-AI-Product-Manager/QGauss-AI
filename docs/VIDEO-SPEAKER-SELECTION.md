# 视频人物选择

口型同步支持在多人画面中指定说话人物。加入一条本人视频及一段声音后，打开「选择说话人物」，找到人物清晰的一帧，点按脸部并保存。也可用方向键微调位置，按住 Shift 每次移动十个原片像素。

人物选择同时记录原视频、参考帧及原画幅位置。显示缩放与画面外的留白不改变原片位置。换帧后需要重新点选；关闭弹窗保留原来的选择，清除选择则沿用服务的默认人物处理方式。移除原视频后不会继续携带旧位置。

费用确认展示接受时的人物与画面。本次选择加入报价版本和原请求的内容校验，更改人物位置需要重新确认。网络中断后查询原任务，明确重试仍使用原请求；窗口无法保存恢复记录时不发起生成。

本人历史保留这份选择，带回创作时与本人素材一同复用。公开成片及管理回执不公开原视频标识、人物位置和声音素材。选择和查看画面本身不生成、不扣次。

## 接口

- `GET /api/video/materials/:id/frames`：仅本人可读，返回原显示画幅 `width`、`height` 和按显示顺序排列的 `frames`。每一项是对应画面内部的取样时刻，单位为秒。回执使用 `private, no-store`，每位使用者每分钟最多读取 30 次。
- `POST /api/video/quote`、`POST /api/video/tasks`：口型同步可携带 `speakerSelection: { videoId, frameNumber, x, y }`。帧编号从零开始，位置为原显示画幅的整数像素。额外字段、隐式数字转换、越界位置、无效帧及其他素材的选择均被拒绝。

选帧读取视频的真实时间表，处理变帧率、解码重排和普通剪裁；无法可靠对应的复杂时间编辑会提示重新保存。浏览器须能够播放所选 MP4。选区不额外上传截图，确认生成后仍按原规则向所选服务提供原视频和声音。

原生映射使用 `options.active_speaker_detection` 中的 `auto_detect: false`、`frame_number` 和 `coordinates`。字段依据 [fal Sync 3 接口](https://fal.ai/models/fal-ai/sync-lipsync/v3/api) 与[说话人物选择说明](https://sync.so/docs/developer-guides/speaker-selection)。人物定位不替代真实服务的处理效果验收。
