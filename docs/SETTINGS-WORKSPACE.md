# 站点设置工作台

管理员可以在「系统设置」按站点、注册安全、对话、应用、商业化、图像、上传、额度、上游和演示十个分组查找设置。搜索覆盖全部分组；简体、繁体和英文切换保留编辑内容，模型名称和自定义文案按原文展示。

## 调整与保存

每项设置显示用途、可见范围、默认值及适用的数字范围。使用默认值只改变页面草稿。先「预览这次调整」，核对修改前后，再明确保存；只提交本次改动，一次接受全部内容或全部拒绝。

重新读取和其他页面的已确认更新会补充最新内容，同时保留本人的编辑。相同设置已有变化时，需选择采用最新内容，或保留自己的修改后重新预览。即使数值后来又改回原值，也会要求核对。没有改动的历史旧值会原样保留，不因新的编辑长度上限被截断。

保存得到确认后，站点导航、公告和商业化入口重新读取公开设置；清空公告会同步移除旧公告。浏览器页面之间只传递更新信号，不传递配置内容、账户或登录凭证。

## 回复中断

提交前，当前标签页只保留本人的申请编号及版本，不保存配置内容或邀请码。无法可靠保留编号时会先阻止提交。

回复未完整到达时，页面保留「核对原结果」。读取结果不会重复保存，也不会把上一次成功当成本次结果。离开再回来仍沿用原申请。确认尚未受理的申请可以「结束这次等待」，随后迟到的原提交也不能重新生效；已经保存的内容继续保留。

普通草稿仅保留在本次登录的页面内存中，跨路由返回可继续编辑。邀请码不进入草稿缓存或结果明细；结果只说明是否已填写。退出或更换登录后，不沿用上一登录的草稿。

## 权限与服务准备

读取、保存和找回结果都核对当前有效的管理员身份。失效、撤销、改密后的旧登录及普通账户不能继续操作。每份结果只对发起它的管理员开放；未知编号不披露其他管理员的操作。

邮箱、手机和扫码卡片显示当前配置准备状态。没有读取到状态时显示「待核对」，不会当成已开放。未准备邮件投递时不能开启邮箱必验。保存站点设置不会主动调用模型、发送邮件或短信，也不会发起第三方连接检查。

准备状态与真实服务验收分别处理。真实收信、短信、扫码授权及费用仍需部署者配置后单独验收。

## 接口与升级

管理接口使用 `Cache-Control: no-store`：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/settings/workspace` | 读取当前有效值与字段版本 |
| POST | `/settings/operations/:key` | 保存已预览的变化 |
| GET | `/settings/operations/:key` | 核对原结果 |
| POST | `/settings/operations/:key/close` | 结束尚未受理的申请 |

申请编号为 UUID v4，保存携带各字段读取时的版本。同一申请和相同内容返回原结果，不重写后来保存的值；更换内容需重新预览。保存内容、字段版本及结果同步提交，数据库失败时一起回滚。结果内容使用站点加密配置保护，邀请码在加密前已从明细中移除。

第 49 次迁移为原配置增加版本，并建立保存结果表；原有配置及业务字段保留。旧的 `PUT /settings` 保留小批量明确更新，超过 20 项时要求刷新页面后预览保存，防止旧整表提交覆盖较新的设置。

验收使用合成账户、隔离数据库及本地服务。页面和接口检查不等于真实外部服务、容器运行、生产负载或全站设备验收。
