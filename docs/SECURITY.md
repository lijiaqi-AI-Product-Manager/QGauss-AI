# 安全边界

## 账户与权限

访问凭据与刷新凭据分开管理。刷新支持轮换与登录族撤销；改密、密码重置及封禁使旧凭据失效。一次性链接和邮箱验证码在事务内消费，拒绝过期与重复使用。管理员操作受角色约束，个人资源按所属账户隔离。

密码、验证码、重置链接与秘密草稿不持久保存在前端。页面切换和身份变化会取消或丢弃不再有效的响应，避免旧操作跨账户生效。

## 内容与文件

模型输出作为不可信输入处理。完整回答经 Markdown 解析与 DOMPurify 消毒；流式片段先以文本显示。图表、SVG 和下载同样受到过滤与资源限制。

上传检查内容、大小和类型，不仅依据扩展名。私有文件通过鉴权接口读取，不直接公开存储目录。外部素材读取凭证绑定用途与任务，并受到期限和状态限制。

## 出站连接

渠道地址通过统一安全请求层访问，检查协议、端口、主机和 DNS 解析结果，拒绝凭据嵌入、保留地址及自动重定向。测试仅通过明确配置放行本地模拟服务，不使用全局关闭检查的开关。

渠道密钥采用 AES-256-GCM 加密，接口只返回掩码，编辑留空不覆盖现有值。生产配置缺失或强度不足时拒绝启动。

## 费用与任务

生成请求在接受时保存费用快照并预留次数，完成、失败与取消分别进入结算或返还。账本和任务终态在事务内提交，重复操作和重启不重复扣费。实际服务商的费用仍需结合真实账单验收。

## 部署限制

当前任务调度、限流及恢复机制按单实例运行验证。多实例、外部存储、生产负载、长期监控及离机灾难恢复需要额外验收。运行配置、数据库和备份属于敏感资料，不进入源码提交。

发现问题时，请先通过仓库的私密安全报告渠道联系维护者；不要在公开 Issue 中粘贴有效凭据、个人资料、数据库或可直接利用的攻击细节。未提供私密渠道时，先提交不含敏感细节的联系请求。
